# 🌈 Rainbow Spiral — Python Turtle Graphics

A colorful, expanding spiral created using Python's built-in Turtle graphics module. This project uses loops, geometric patterns, and rainbow colors to create visual art with code.

## 🛠️ Built With

- **Python** — Programming language
- **Turtle** — Drawing graphics using code
- **Colorsys** — Generating rainbow colors using HSV-to-RGB conversion

## 🚀 Getting Started

### Prerequisites

Install Python 3 on your computer. The `turtle` and `colorsys` modules are included with standard Python installations.

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/jainparii2008-arch/rainbow-spiral-python.git
   ```

2. Open the project folder:

   ```bash
   cd rainbow-spiral-python
   ```

3. Run the program:

   ```bash
   python sun.py
   ```
